# Install XM6 Studio

## [Download the ready-to-install app](https://github.com/IamShaharFar/xm6-studio/raw/refs/heads/main/downloads/XM6-Studio-1.0.1-Apple-Silicon.zip)

Version **1.0.1**, build **4**. Requires an **Apple Silicon Mac (M1 or later)**, **macOS 15 or later**, and **Sony WH-1000XM6** headphones.

Unzip the download and drag **XM6 Studio.app** to **Applications**. You do not need development tools. Follow the included **START HERE.txt** guide for first launch, Bluetooth permission and Mac/iPhone setup.

The ZIP includes the app, installation instructions, feature coverage, verification report and the matching packaged source archive. The app is locally ad-hoc signed, without Apple Developer ID signing or notarization. macOS may require the per-app **Open Anyway** step described in the guide.
